# Explicit Chat Filter Resolution and Currency/Duration-Scoped Offer Filtering (Extends ADR 0018)

Internal AI chat search tools (`list_motorcycles` and `list_shops`) normalize common rider location, brand, and model aliases—stripping diacritics, splitting `"City, Country"` qualifiers, mapping curated city aliases, separating leading manufacturer names from `"Brand Model"` queries, and matching spacing/hyphen variants against Canonical Model Names—so natural phrasing resolves to published Catalog Listings, while any explicit entity filter (`city`, `country`, `countryCode`, `shop`, `brand`, or `category`) that still fails to resolve returns zero rows (`total: 0`) alongside structured `unresolvedFilters` metadata rather than silently dropping the unresolved constraint and returning unrelated global inventory. Across Rental Offer evaluation, motorcycle search services, `GET /api/v1/motorcycles`, and internal chat tools, price filtering preserves ADR 0018's standalone-`daily` default when `durationDays` is omitted, enforces strict 3-letter ISO `currency` matching when `currency` is supplied without volatile exchange-rate conversion, evaluates covering standalone `daily` brackets (`offer_type = 'daily'`, `billing_basis = 'per_day'`, `duration_unit = 'day'`) plus exact-duration fixed-day `package` Daily Equivalents (`offer_type = 'package'`, `billing_basis = 'package_total'`, `duration_unit = 'day'`, fixed duration equal to `durationDays`, `round(amount / durationDays, 2)`) when `durationDays` is supplied—never dividing `calendar_month` offers by 30 or extrapolating hourly, extension, or non-matching package durations—and excludes unpriced `"Price on request"` listings whenever `minPrice`, `maxPrice`, or `knownPriceOnly` is set.
