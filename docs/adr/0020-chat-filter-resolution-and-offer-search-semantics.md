# Explicit Chat Filter Resolution and Currency/Duration-Scoped Offer Filtering (Extends ADR 0004 & ADR 0018)

Internal AI chat search tools (`list_motorcycles` and `list_shops`) normalize common rider location, brand, and model aliases—stripping diacritics, splitting `"City, Country"` qualifiers, mapping curated city aliases, separating leading manufacturer names from `"Brand Model"` queries, and matching spacing/hyphen variants against Canonical Model Names—so natural phrasing resolves to published Catalog Listings, while any explicit entity filter (`city`, `country`, `countryCode`, `shop`, `brand`, or `category`) that still fails to resolve returns zero rows (`total: 0`) alongside structured `unresolvedFilters` metadata rather than silently dropping the unresolved constraint and returning unrelated global inventory. Across Rental Offer evaluation, motorcycle search services, `GET /api/v1/motorcycles`, and internal chat tools, price filtering preserves ADR 0018's standalone-`daily` default when `durationDays` is omitted, enforces strict 3-letter ISO `currency` matching when `currency` is supplied without volatile exchange-rate conversion, evaluates covering standalone `daily` brackets (`offer_type = 'daily'`, `billing_basis = 'per_day'`, `duration_unit = 'day'`) plus exact-duration fixed-day `package` Daily Equivalents (`offer_type = 'package'`, `billing_basis = 'package_total'`, `duration_unit = 'day'`, fixed `days > 1`: `durationDays > 1 && min_duration === durationDays && max_duration === durationDays`, `round(amount / durationDays, 2)`) when `durationDays` is supplied—never dividing `calendar_month` offers by 30 or extrapolating hourly, extension, or non-matching package durations—and excludes unpriced `"Price on request"` listings whenever `minPrice`, `maxPrice`, or `knownPriceOnly` is set.

## Shop Reference Resilience, Colloquial Brand-Model Aliases, and Token-Span Model Matching

- **Hyphen-, Diacritic- & Lossy-Slug-Resilient Shop Lookup**: Shop reference resolution (`resolveShopReference`) and shop text search (`getShops`) preserve raw punctuation and Unicode forms alongside diacritic-stripped (`đ`/`Đ` -> `d`/`D` plus Unicode NFD mark stripping) and hyphen-fused slug/prefix clauses (`"Mr-Good Bikes"` <-> `"mrgood-bikes"`), falling back to a single narrow active-shop lookup scoped by `cityId`/`countryCode` (without loading fleets or `content_sections`) scored across normalized names, compact alphanumeric keys, and vowel-stripped consonant skeletons so ASCII queries match accented shop names (`"Gia Hưng Motorbike Rental"`) and legacy vowel-dropped slugs (`"gia-hng-motorbike-rental"`).
- **Colloquial `"Honda Win"` / `"Detech Win"` Alias & `"Brand Model"` Prefix Precedence**: Curated `Detech` manufacturer attribution remains authoritative in storage and display (per ADR 0004), while search-time `"Win"` model-family queries (`"Honda Win"`, `"Detech Win"`, or `brand = Honda` + `Win`) expand across `{Honda, Detech}` so published `Detech` `Win` Catalog Listings resolve with `brand: "Detech"` intact; when a `"Brand Model"` query begins with an explicit catalog brand followed by a non-empty model remainder (e.g., `brand: "Honda", query: "Detech Win"`), the explicit brand prefix in `query` takes precedence over the conflicting `brand` parameter.
- **Full Alphanumeric Token-Span Canonical Model Matching & Exact-Match Ranking**: Canonical Model Name matching tokenizes candidate and target model strings into contiguous letter and digit sub-tokens (`[a-z]+|[0-9]+`) and matches only when a full contiguous token span of the candidate equals the normalized target—preserving fused/hyphenated equivalents (`"XADV 750"` <-> `"X-ADV 750"`, `"CBR500R"` <-> `"CBR 500 R"`, `"AirBlade"` <-> `"Air Blade"`, `"PG1"` <-> `"PG-1"`) and matching `"Win"` to `"Win"` and `"WIN 125"` while rejecting mid-token collisions (`"Winner"`, `"Africa Twin"`, `"Gold Wing 1800"`). When multiple canonical models match, exact normalized model matches rank ahead of multi-token variants prior to pagination slicing while preserving secondary sort order within each group.
