# Agent-Computed Change Proposals (Supersedes ADR 0003 and ADR 0015)

External ingestion agents receive the rental shop's full current database state (active motorcycles with their `id`, `brand`, `model`, `year`, `year_to`, `engine_capacity_cc`, `source_url`, and `rates`, plus current shop profile, `inclusions`, and `conditions`) directly from `GET /api/agent/tasks`, compare the live website against that database baseline, and submit an explicit 1-to-1 `items` array (`add`, `update`, `delist`, `unchanged`) to `POST /api/agent/change-proposals`. The RV2 backend no longer runs a server-side diff engine (`services/diff-engine.ts`), heuristic identity reconciliation, or `Identity Review` workflow; instead, it performs lightweight structural and geodata-immutability validation and stages the agent's explicit Change Proposal Items directly for administrator review.
