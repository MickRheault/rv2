# Agent-Computed Change Proposals (Supersedes ADR 0003 and ADR 0015)

External ingestion agents receive the rental shop's full current database state (active motorcycles via `existingInventory` with `id`, `brand`, `model`, `year`, `year_to`, `engineCapacityCc`, `availabilityStatus`, `sourceUrl`, `rates`, and `conditions` (`{ condition_type_id, name, notes }[]`), plus canonical `conditionTypes` (`{ id, name }[]`) and current shop profile via `currentShop` with `id`, `providerName`, `businessDescription`, `phone`, `website`, `inclusions`, and `conditions`) directly from `GET /api/agent/tasks`, compare the live website against that database baseline, and submit an explicit 1-to-1 `items` array (`add`, `update`, `delist`, `unchanged`) to `POST /api/agent/change-proposals`. The GMR backend performs structural, condition-type, and geodata-immutability validation, stages the agent's explicit Change Proposal Items directly for administrator review, and atomically persists approved motorcycle conditions (`motorcycle_conditions`) while preserving omitted conditions and existing rental rate tiers.
